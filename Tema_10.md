```python
import time
def runtime(func):
    def wrapper(*args):
        start=time.time()
        result=func(*args)
        end=time.time()
        run_time=end-start
        print('      Function runtime:',run_time,'s')
        return result
    return wrapper
@runtime
def fibonacci():
    fib1=fib2=1
    for i in range(2,200):
        fib1,fib2=fib2,fib1+fib2
    print(fib2,end=' ')
if __name__=="__main__":
    fibonacci()
```

То есть, мы имеем дело с декоратором - функция runtime() является декоратором для fibonacci(), о чём говорит строчка `@runtime` перед последней - ссылка на декоратор. В самом декораторе runtime() выполняется вычисление времени выполнения функции по разности между моментами времени до и после запуска функции с её аргументами, принятыми в списке `*args`. ## Самостоятельная работа №5
### Создайте собственное исключение, которое будет использоваться в двух любых фрагментах кода. Исключения, которые использовались ранее в работе нельзя воссоздавать.
```python
class NumTooLongFor32bitError(Exception):
    def __init__(self,err):
        super().__init__(err)
def fibo(n):
    fib1,fib2=1,1
    for i in range(2,n+1):
        fib1,fib2=fib2,fib1+fib2
        if fib2>2147483647:
            raise NumTooLongFor32bitError("Fibonacci number #"+str(n)+" is too long to fit in 32-bit integer")
    return fib2
def fact(n):
    mul=1
    for i in range(2,n+1):
        mul*=i
        if mul>2147483647:
            raise NumTooLongFor32bitError("Factorial of "+str(n)+" is too long to fit in 32-bit integer")
    return mul
if __name__=="__main__":
    try:
        print(fact(13))
    except NumTooLongFor32bitError as e:
        print(e)
    finally:
        try:
            print(fibo(45))
        except NumTooLongFor32bitError as e:
            print(e)
```

## Выводы

Данная программа содержит собственное исключение NumTooLongFor32bitError и две функции fibo() и fact(). Конструктор класса-исключения принимает в себя аргумент - сообщение об ошибке, задаваемое во время работы программы, и передаёт его конструктору класса Exception. Функция fibo() с входным параметром n позволяет вычислить n+1-е число Фибоначчи по такому же принципу, как и в самостоятельной работе №1 (через цикл), с единственным отличием - если число окажется больше 2147483647 (а это максимальное положительное число, которое можно хранить в 32-битных числах), то цикл обрывается и выбрасывается исключение NumTooLongFor32bitError с ошибкой "Fibonacci number #(n) is too long to fit in 32-bit integer". Если же цикл закончился без ошибки, то значение fib2 выводится как возвращаемое значение. Функция же fact(), тоже с входным параметром n, позволяет вычислить факториал числа n - произведение всех натуральных чисел от 1 до n. Произведение рассчитывается в цикле, и если во время итерации цикла обнаруживается, что значение факториала переваливает за 2147483647, то выбрасывается исключение NumTooLongFor32bitError с ошибкой "Factorial of (n) is too long to fit in 32-bit integer". В противном случае значение факториала выводится как возвращаемое значение. При запуске программы вызываются функции fact() с аргументом 13 и fibo() с аргументом 45, затем их значения выводятся в консоль, причём запуск первой функции осуществляется во внешней конструкции try/except/finally, в части except NumTooLongFor32bitError которой выводится сообщение об ошибке в консоль, а второй - во вложенной в части finally конструкции try/except, в которой в части except NumTooLongFor32bitError также выводится сообщение об ошибке. То есть, если ошибка произойдёт во время выполнения функции fact(), то функция fibo() всё равно запустится далее по ходу программы, что и представлено в результате на скриншоте выше.

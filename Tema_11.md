## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобными применением.

```python
class Countdown:
    def __init__(self,start):
        self.count=start+1
    def __iter__(self):
        return self
    def __next__(self):
        self.count-=1
        if self.count<0: raise StopIteration
        return self.count
if __name__=="__main__":
    counter=Countdown(5)
    for i in counter: print(i)
```

## Самостоятельная работа №1
### Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```python
def fib(n):
    f1,f2=1,1
    for i in range(n):
        yield f1
        f1,f2=f2,f1+f2
if __name__=="__main__":
    fibi=fib(200)
    for i in fibi: print(i)
```

![скрин](https://github.com/a-arkham-3005/program_engineering/blob/Тема_11/screens/sam1.png)

## Выводы

Данная программа содержит в себе генератор fib(n), который при вызове с аргументом, записываемый в параметр n (порядок необходимого числа Фибоначчи), сначала создаёт переменные f1 и f2, храня в них первые два числа Фибоначчи, равные 1, затем через цикл, прогоняемый n-1 раз, во время каждой итерации сначала выводит значение f1 туда, откуда вызывают каждое значение из генератора, по команде `yield`, затем обновляет переменные f1 и f2, устанавливая им одновременно значения соответственно f2 и f1+f2, таким образом получая те самые числа Фибоначчи. Таким образом генератор не хранит все промежуточные значения непосредственно в памяти, а вызывается, как итератор, в конструкции for..in, где и происходит вывод информации из генератора по каждому индексу. При запуске программы она сначала задаёт генератор fib() с аргументом 200 по ссылке fibi, затем прогоняет этот генератор, выводя в консоль поочерёдно все числа Фибоначчи от первого до 200-го. Результат выполнения программы представлен на скриншоте выше.

## Самостоятельная работа №2
### К коду предыдущей задачи добавьте запоминание каждого числа Фибоначчи в файл “fib.txt”, при этом каждое число должно находиться на отдельной строчке. Результатом выполнения задачи будет листинг кода и скриншот получившегося файла.

```python
def fib(n):
    f1,f2=1,1
    for i in range(n):
        yield f1
        f1,f2=f2,f1+f2
if __name__=="__main__":
    fibi=fib(200)
    with open("fib.txt","w") as f:
        for i in fibi: f.write(str(i)+"\n")
```

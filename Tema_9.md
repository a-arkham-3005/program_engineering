### Вам дали важное задание: написать продавцу мороженого программу, которая будет писать, добавили ли топпинг в мороженое, и цену после возможного изменения. Для этого вам нужно написать класс, в котором будет определяться, изменили ли состав мороженого или нет. В этом классе реализуйте метод, выводящий на печать «Мороженое с {ТОППИНГ}» в случае наличия добавки, иначе отобразится следующая фраза: «Обычное мороженое». ```python
class Icecream:
    def __init__(self,ingredient=None):
        if isinstance(ingredient,str): self.ingredient=ingredient
        else: self.ingredient=None
    def composition(self):
        if self.ingredient:
            print(f"Мороженое с: {self.ingredient}")
        else: print("Обычное мороженое")

```python
class Russian:
    @staticmethod
    def greeting():
        print("Привет")
class German:
    @staticmethod
    def greeting():
        print("Hallo")
def greet(lang):
    lang.greeting()
ivan=Russian()
greet(ivan)
hans=German()
greet(hans)
```

```python
class Tomato:
    states=['Missing','Blossom','Green','Red']
    def __init__(self,index):
        self._index=index
        self._state=Tomato.states[0] # свойства _index и _state являются protected - доступ из класса и подклассов
    def grow(self):
        if self._state==Tomato.states[0]: self._state=Tomato.states[1]
        elif self._state==Tomato.states[1]: self._state=Tomato.states[2]
        elif self._state==Tomato.states[2]: self._state=Tomato.states[3]
    def is_ripe(self):
        return self._state==Tomato.states[3]
class TomatoBush:
    def __init__(self,num):
        self.tomatoes=[]
        for i in range(num):
            self.tomatoes.append(Tomato(i))
    def grow_all(self):
        for i in self.tomatoes:
            i.grow()
    def all_are_ripe(self):
        for i in self.tomatoes:
            if not i.is_ripe(): return False
        return True
    def give_away_all(self):
        self.tomatoes.clear()
class Gardener:
    def __init__(self,name,bush):
        self.name=name # это свойство публично - доступно для чтения и записи везде
        self._plant=bush # это свойство protected - доступ для класса и подклассов
    def work(self):
        self._plant.grow_all()
        print("Поработали, поухаживали..")
    def harvest(self):
        if not self._plant.all_are_ripe(): print("Не все плоды ещё созрели.")
        else:
            self._plant.give_away_all()
            print("Урожай собран!")
    @staticmethod
    def knowledge_base():
        print("Инструкция по садоводству:")
        print("Для садоводства необходимо создать сначала куст с помидорами - объект TomatoBush с количеством помидоров,")
        print("затем садовода - объект Gardener со ссылкой на объект TomatoBush. Для ухаживания за кустом используйте для")
        print("садовода метод work(), а для сбора урожая - метод harvest(). Собрать можно только созревший урожай. Продол-")
        print("жайте работать над кустом, и получите урожай.")
Gardener.knowledge_base()
tb=TomatoBush(6)
grd=Gardener("Manfred",tb)
grd.work()
grd.harvest()
grd.work()
grd.work()
grd.harvest()
```

## Выводы

Данная программа написана с помощью объектно-ориентированного программирования: присутствуют классы Tomato, TomatoBush и Gardener. В первом, Tomato, присутствуют статический атрибут states со стадиями роста помидора, конструктор объекта `__init__`, устанавливающий атрибуты для объекта `_index` и `_state` (соответственно хранящие номер и стадию роста) (как и сказано в комментариях к коду, оба атрибута являются protected - доступ к ним разрешён из класса и подклассов, а также чтение в пределах программы), и методы grow(), переводящий помидор в следующую стадию роста, и is_ripe(), проверяющий, является ли стадия роста последней, и возвращающая True в этом случае и False в противном. В классе TomatoBush в конструкторе устанавливаются единственный атрибут (публичный) объекта "tomatoes" со списком, содерщащий определённое количество объектов класса Tomato с индексами по порядку. В самом классе присутствуют методы для объектов grow_all(), вызывающий метод grow() для всех объектов в списке tomatoes, и all_are_ripe(), вызывающий для этих же объектов функцию is_ripe() и возвращающий True в том случае, если все выведенные значения являются True, а иначе False. Также здесь есть метод give_away_all(), очищающий список tomatoes. В последнем классе Gardener конструктором задаются атрибуты name (публичный, как и сказано в комментарии - доступ отовсюду) и `_plant` (защищённый protected, как и сказано в комментарии) - в качестве значения `_plant` принимается готовый объект TomatoBush. Такая зависимость одного класса от другого называется ассоциацией, или связью HAS-A. Также в классе присутствуют методы work(), вызывающий для объекта по ссылке `_plant` метод grow_all(), и harvest(), вызывающий метод all_are_ripe() для объекта `_plant`, и если выведено True, то вызывается для этого же объекта метод give_away_all(). А также в этом классе есть статический метод (принадлежащий не объектам, а классу в целом) knowledge_base(), выводящий в консоль справку по садоводству. Все действия в методах класса Gardener выводятся в консоль. После инициализации классов, атрибутов и методов, начинается основной код программы, содержащий тесты, указанные в задании. Сначала вызывается статический метод knowledge_base() по классу Gardener. Затем создаются два объекта: tb класса TomatoBush с параметром 6 (количество объектов Tomato в списке tomatoes), затем grd класса Gardener с параметрами "Manfred" (имя) и tb (ссылка на объект TomatoBush).
